# CodeAlpha Internship - Task 2
## Exploratory Data Analysis (EDA) on Titanic Dataset

## Project Overview
This project is part of the CodeAlpha Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic dataset to understand the data, identify patterns, detect missing values, and visualize important insights using Python.

---

## Dataset
- Dataset Name: Titanic Dataset
- File: Titanic-Dataset.csv
- Source: Kaggle

---

## Tools and Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (VS Code)

---

## Exploratory Data Analysis Performed

### Data Exploration
- Loaded the dataset
- Displayed the first five rows
- Checked dataset shape
- Viewed column names
- Examined data types
- Generated statistical summary

### Data Quality Check
- Identified missing values
- Checked duplicate records

### Questions Asked
- How many passengers survived?
- How many passengers did not survive?
- Does gender affect survival?
- Which passenger class had the highest survival rate?
- What is the age distribution of passengers?
- Are there any missing values in the dataset?

### Visualizations Created
- Survival Count
- Gender Distribution
- Age Distribution
- Passenger Class Distribution
- Survival by Gender
- Correlation Heatmap
- Fare Box Plot

---

## Key Findings
- More passengers did not survive than survived.
- Female passengers had a higher survival rate than male passengers.
- Most passengers traveled in Third Class.
- Most passengers were between 20 and 40 years old.
- Some columns contained missing values.
- The Fare column included several outliers.

---

## Conclusion
This Exploratory Data Analysis helped understand the Titanic dataset by exploring its structure, identifying missing values, analyzing passenger characteristics, and visualizing important trends. The insights gained from this analysis can be useful for further data analysis and predictive modeling.
